Nexa Desktop 主进程启动时序

01 · 数据层就绪

initDatabase() 加载 sql.js(WASM)，读取 ~/.nexa/nexa.db；不存在则建库执行 schema，旧库逐列做轻量迁移（ALTER TABLE 失败即视为已存在），并把上次崩溃残留的 running run 收敛为 paused。

02 · 服务装配

实例化专家 / Skill / 连接器 / 知识库 / 记忆 / AgentRuntime 六类内存服务；随后 scheduler.start() 起 20s 轮询 tick，RelayClient.start(relayUrl) 建立长连接（指数退避重连）。

03–04 · 监听、窗口与渲染端

registerIpcHandlers() 注册全部 ipcMain.handle，并让产物预览 HTTP 服务监听 127.0.0.1 随机端口。窗口以 show:false 创建，ready-to-show 后才显示以避免白闪；渲染端经 preload.cjs 订阅 agent:event、拉设置与专家，未初始化则弹三步引导。
